# MOD510 Projects  

This repository contains projects from **MOD510 – Modeling and Computational Engineering**.  
The course introduces **numerical methods** and **modeling techniques** used to solve practical problems across several engineering disciplines.  

---

## Project 1 – *Automatic for the People*  
**Learning Objectives:**  
- Gain experience in structuring and writing technical reports.  
- Write custom functions and classes in Python.  
- Explore numerical round-off and truncation errors.  
- Learn to use Python libraries for scientific computing.  

---

## Project 2 – *Can You Hear the Size of a Reservoir?*  
**Learning Objectives:**  
- Implement numerical solvers for the **radial diffusivity equation**.  
- Compute pressure as a function of distance from a well under steady-state and transient flow.  
- Compare the steady-state model to an analytical solution.  
- Apply the time-dependent model to study pressure decline in a well and estimate reservoir size from well test data.  
- Investigate performance differences between **sparse** and **dense matrix solvers**.  

---

## Project 3 – *Stirred (not shaken)*  
**Learning Objectives:**  
- Implement an ODE solver using the Euler, Runge-Kutta (second and fourth order) algorithm
- Use mixing tank models to model how the shape of a medical tracer changes after traveling in an aorta arch
- Compare the ODE model to CFD simulation results and extract information about the cardiac output (flooding rate) and volume of the aortic arch
- Investigate if one can use the tracer signal to identify if there is a an aneurysm in the aorta
  
---

## Project 4 - *Monte carlo methods*
**Learning Objectives:**  
- Understand the principles of Monte Carlo methods and their application in stochastic modeling.
- Develop skills in formulating and solving mass balance equations for single and interconnected systems.
- Quantify uncertainties in simulation results and interpret their implications for system behavior.
- Compare stochastic simulation outcomes to deterministic ODE solutions, critically analyzing their performance and limitations.
- Gain hands-on experience with computational tools for solving engineering problems.
