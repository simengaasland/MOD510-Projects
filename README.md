# MOD510 Projects  

This repository contains projects from **MOD510 – Modeling and Computational Engineering**.  
The course introduces **numerical methods** and **modeling techniques** used to solve practical problems across several engineering disciplines.  

---

## Project 1 – *Automatic for the People*  
**Learning Objectives:**  
- Gain experience in structuring and writing technical reports.  
- Write custom functions and classes in Python.  
- Explore numerical round-off and truncation errors.  
- Learn to use Python libraries for scientific computing.  

---

## Project 2 – *Can You Hear the Size of a Reservoir?*  
**Learning Objectives:**  
- Implement numerical solvers for the **radial diffusivity equation**.  
- Compute pressure as a function of distance from a well under steady-state and transient flow.  
- Compare the steady-state model to an analytical solution.  
- Apply the time-dependent model to study pressure decline in a well and estimate reservoir size from well test data.  
- Investigate performance differences between **sparse** and **dense matrix solvers**.
